CASE / 01

多分店排班與營運管理：告別紙本與人工對帳

養生會館多分店即時排班與營運管理系統

原本仰賴紙本排班與人工派單，櫃台與休息室資訊不同步，拆帳與優惠券計算也耗時。

建置多品牌／多分店權限、價目表與拆帳模組，使用 Flask-SocketIO 同步各空間資訊，並串接通知 Bot。

成果：營運流程數位化、跨空間秒級同步，減少每日對帳時間。

FLASK · WEBSOCKET · LINE / TELEGRAM BOT
CASE / 02

伺服器遷移與服務整合：降低舊系統維護負擔

25+ 台核心伺服器 P2V 遷移與服務重構

實體主機老化與舊服務累積，增加維護成本與營運風險。

主導 20 台正式與 5 台測試主機遷移，與 DBA 協作 Oracle 對接，並整合 MariaDB、Memcached 等服務。

成果：降低實體機房維護負擔，簡化服務管理與部署。

LINUX · P2V · TOMCAT · MEMCACHED
CASE / 03

設計 ETL 與資料修復、模組化回測引擎、Random Forest 評估，並封裝永豐金 Shioaji API。

成果：透過模組化工具改善資料準備與策略驗證效率。

SHIOAJI · PANDAS / ETL · BACKTEST · RANDOM FOREST
